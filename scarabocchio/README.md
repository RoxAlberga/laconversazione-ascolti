# È uno scarabocchio o uno spartito? 🎼🖍️

Un gioco per mettere alla prova il tuo occhio (e il tuo orecchio interiore): a ogni partita
ti vengono mostrate 10 immagini e devi indovinare se ognuna è **la pagina di uno spartito
d'avanguardia** o **uno scarabocchio qualsiasi**. Quando premi il tasto scopri la verità —
e quando è uno spartito, anche **di chi è**, con una curiosità sull'opera.

Nel Novecento le avanguardie musicali hanno riempito le partiture di cerchi, macchie, linee
e geometrie misteriose: la cosiddetta **notazione grafica**. Il risultato è che certi
spartiti sembrano scarabocchi — e certi scarabocchi sembrano spartiti. Questo gioco vive
esattamente su quel confine.

## L'archivio

- **Oltre 50 spartiti** ispirati a vere partiture grafiche e innovative: Cage (da *Aria* a
  *4′33″*), Cardew, Penderecki, Ligeti, Xenakis, Stockhausen, Feldman, Earle Brown, Berio,
  Berberian, Bussotti, **Guaccero**, **Donatoni**, Kagel, Haubenstock-Ramati, Logothetis,
  Wolff, La Monte Young, Takemitsu, Lutosławski, **Maderna**, Pousseur, Schnebel, Schafer,
  Schaeffer, **Russolo**, **Chiari**, Kurtág, Ichiyanagi, Braxton e Crumb.
- **50 scarabocchi** di ogni natura: ghirigori, gomitoli nervosi, schemini con le frecce,
  caricature e faccine, omini stilizzati, casette col sole, cubi 3D, partite di tris,
  finta scrittura, occhi con le ciglia, ragnatele, labirinti, razzi e barchette.

A ogni partita ne vengono pescati 10 a caso (5 e 5, in ordine casuale).

## Come si gioca

1. Apri `index.html` in un browser (oppure gioca online se il sito è pubblicato con GitHub Pages).
2. Osserva l'immagine e scegli: **Scarabocchio** o **Spartito**?
3. Dopo ogni risposta scopri la verità, l'autore dello spartito e una piccola storia.
4. Alla fine ricevi punteggio e titolo onorifico, dalla *"Vittima designata
   dell'avanguardia"* all'*"Orecchio assoluto dell'avanguardia"*.

## Come funziona

Tutte le immagini sono **generate proceduralmente** in SVG a ogni partita: nessuna è una
riproduzione di una partitura reale. Gli "spartiti" imitano lo stile grafico delle opere
citate; gli scarabocchi imitano noi durante una riunione noiosa.

## Tecnologia

Un singolo file `index.html` senza dipendenze: HTML, CSS e JavaScript puro. Funziona
offline e si può pubblicare così com'è su GitHub Pages.
